# Разработка

Как поднять проект с нуля, как с ним работать каждый день и на какие грабли
здесь уже наступали. Устройство системы — в [ARCHITECTURE.md](ARCHITECTURE.md),
правила клуба — в [SPEC.md](SPEC.md).

Все команды — **из корня репозитория** (папка `cinema-club/`, там лежит
`README.md`). Проверить: `pwd` оканчивается на `/cinema-club`.

## С нуля до запущенного приложения

### 1. Что нужно на машине

* **Python 3.12** — `python3 --version`.
* **Postgres 16 на порту 5433.** Порт именно такой, чтобы не столкнуться
  с чужим Postgres на 5432 — и в разработке, и в бою. Два способа, оба дают
  одинаковый `DATABASE_URL`:
  * **Docker** — проще всего, порт уже настроен:
    ```bash
    docker compose up -d          # только база, 5433 наружу
    ```
  * **Локально через brew** (так сделано на машине, где проект писался):
    ```bash
    brew install postgresql@16
    # порт по умолчанию 5432 — меняем на 5433:
    sed -i '' 's/^#*port = .*/port = 5433/' /opt/homebrew/var/postgresql@16/postgresql.conf
    brew services start postgresql@16
    createuser -s cinema -p 5433 && createdb -O cinema -p 5433 cinema
    psql -p 5433 -d cinema -c "alter user cinema password 'cinema'"
    ```
* **Node 20 или новее** и npm — для Mini App (в разработке стоит 26).

### 2. Зависимости

```bash
cd backend && python3 -m venv venv && ./venv/bin/pip install -r requirements-dev.txt && cd ..
cd miniapp && npm install && cd ..
```

`requirements-dev.txt` включает рабочие зависимости плюс pytest и ruff —
в бою ставится только `requirements.txt`, без них.

### 3. Токены и `.env`

```bash
cp .env.example .env
```

Что где взять:

| Ключ | Где взять | Без него |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` | не работает ни вход, ни бот, ни локальный просмотр |
| `BOOTSTRAP_SUPERADMIN_TG_ID` | написать [@userinfobot](https://t.me/userinfobot) | никто не получит права главного админа |
| `SECRET_KEY` | `openssl rand -hex 32` | сессии не подписать |
| `KINOPOISK_API_TOKEN` | [kinopoisk.dev](https://kinopoisk.dev/) — бесплатный | нечем наполнить каталог |
| `TMDB_API_TOKEN` | [themoviedb.org](https://www.themoviedb.org/settings/api) — **API Read Access Token (v4)**, длинный JWT | не будет поиска новых фильмов и оценок TMDB |
| `MINIAPP_URL` | адрес туннеля в разработке, домен в бою | бот не подставит кнопку Mini App |
| `DATABASE_URL` | уже заполнен под локальную базу | — |

Кинопоиск помечен в примере как опциональный по историческим причинам: на деле
каталог наполняется из него, так что для рабочей установки он нужен.

### 4. Схема и каталог

```bash
cd backend && ./venv/bin/alembic upgrade head && cd ..
cd backend && ./venv/bin/python -m app.import_top --source kinopoisk --list popular --limit 1500 && cd ..
```

Второй шаг завозит полторы тысячи фильмов — столько нужно ленте, чтобы её
хватило больше чем на вечер. Для быстрого старта хватит `--limit 100`.
Импорт идемпотентен, повторный запуск обновляет карточки.

### 5. Запуск

Три терминала:

```bash
cd backend && ./venv/bin/uvicorn app.main:app --reload --reload-include ../.env
cd miniapp && npm run dev            # :5173, проксирует /api на бэкенд
cd backend && ./venv/bin/python -m app.bot
```

`--reload-include ../.env` обязателен: uvicorn следит только за `.py`, а
конфигурация читается один раз при старте. Без флага правка токена не
подхватится, и приложение будет уверять, что токен не задан.

Swagger — http://localhost:8000/docs.

### 6. Посмотреть глазами пользователя

Telegram не принимает `localhost` и `http`, поэтому для настоящего Mini App
нужен HTTPS-туннель:

```bash
scripts/tunnel.sh
```

Скрипт держит туннель, пишет адрес в `.env` и переподключается сам, когда
бесплатный лимит (около часа) истекает. BotFather править не нужно: запущенный
бот следит за `.env` и переставляет кнопку меню через `setChatMenuButton`.

Если Telegram не нужен — быстрее и надёжнее локальный просмотр:

```bash
scripts/preview.sh          # последний коммит
scripts/preview.sh pr-1     # любая ветка или ревизия
```

Он поднимает свои копии бэкенда и фронтенда (порты 8011/5175), сеет демо-данные
и печатает по ссылке на каждую роль. Подробности — в
[README](../README.md#просмотр-интерфейса-локально).

**Смотрится ревизия, а не рабочая копия:** `git archive` не видит
незакоммиченного. Чтобы посмотреть правки до коммита, поднимите то же самое
руками из рабочего дерева:

```bash
cd backend && ./venv/bin/python -m uvicorn app.main:app --port 8011 &
cd backend && ./venv/bin/python -m app.preview_seed
cd miniapp && VITE_API_URL=http://localhost:8011 npx vite --port 5175 --strictPort &
cd backend && ./venv/bin/python -m app.dev_login --tg-id 900001 --name "Зритель Демо"
```

Последняя команда печатает подписанную `initData` — её надо
URL-закодировать и открыть как `http://localhost:5175/?initData=<строка>`.

## Ежедневная работа

### Тесты

```bash
cd backend && ./venv/bin/python -m pytest -q          # 396 тестов
cd backend && ./venv/bin/python -m pytest tests/test_weights.py -q -k затухание
cd miniapp && npm test                                 # 24 теста
```

Тесты бэкенда работают на **отдельной базе `cinema_test`**: она создаётся сама,
схема разворачивается один раз за прогон, а таблицы чистятся `TRUNCATE` после
каждого теста — рейтинги считаются по всей базе, и остатки от соседнего теста
молча исказили бы результат. Рабочие данные не трогаются, но Postgres на 5433
должен быть запущен.

Полезное из `tests/conftest.py`:

* фикстура `session` — чистая база и сессия SQLAlchemy;
* фикстура `client` — HTTP-клиент поверх приложения; **закрытая бета в нём
  выключена**, иначе каждый тест начинался бы с ввода кода (гейт проверяется
  отдельно, в `test_invites.py`);
* `login(client, tg_id, name)` — вход с подписанной initData;
* `set_shortlist(...)` и `open_shortlist_window(session)` — сборка шорт-листа
  открыта только со среды 20:00 до четверга 08:00, и без этих помощников
  половина тестов падала бы по календарю.

### Линтеры

```bash
cd backend && ./venv/bin/ruff check app tests && ./venv/bin/ruff format app tests
cd miniapp && npm run lint && npm run build
```

`npm run build` — это `tsc -b && vite build`; **проверяйте им, а не только
`npx tsc --noEmit`**: проектные ссылки собираются иначе, и ошибка вроде
повторного экспорта видна только в сборке.

### Как добавить функциональность

Порядок, который в этом проекте работает:

1. **Модель** — в `backend/app/models/*.py`, если нужны новые таблицы или
   колонки.
2. **Миграция** — вручную, файлом в `backend/alembic/versions/` по образцу
   соседних: имя `YYYYMMDD_HHMM_кратко.py`, `revision`/`down_revision`
   прописаны явно. Для нового значения enum'а не забудьте пересобрать CHECK
   (пример — `20260909_1800_admin_broadcast.py`).
3. **Сервис** — в `backend/app/services/`. Вся логика здесь: HTTP и Telegram
   сервис знать не должен. Ошибки — своим исключением (`XxxError(ValueError)`)
   с текстом, который можно показать человеку.
4. **API** — роутер в `backend/app/api/`: перевести HTTP в вызов сервиса,
   исключение — в код ответа. Права — через `CurrentUser` / `RequireAdmin` /
   `RequireSuperadmin`.
5. **Схемы** — `backend/app/schemas.py` (pydantic), и такой же тип в
   `miniapp/src/types.ts`.
6. **Фронтенд** — вызов в `api.ts`, экран или компонент, стили в `index.css`.
7. **Тесты** — на сервис (быстрые, на `session`) и хотя бы один на HTTP
   (`client`). Тест описывает правило словами в docstring: через полгода это
   единственное, что объяснит, почему так.

### Соглашения по коду

* **Комментарий объясняет «почему», а не «что».** Кода видно и так; неочевидно
  решение. Так написан весь проект — держите тон.
* **Русский в комментариях, докстрингах и текстах для людей**, английский в
  именах. Так уже везде.
* `ruff` с `line-length = 100`, правила `E,F,I,UP,B`.
* Ссылки на спек — `§N` в комментарии рядом с правилом, которое он требует.
* SQL — выражениями SQLAlchemy, не строками, кроме мест, где иначе нельзя
  (пример: хеш-функция в `deck.py`).

## Грабли

Собраны по следам реальных поломок — каждая стоила времени.

**TMDB недоступен из некоторых сетей.** В той, где велась разработка, DNS
подменяет `api.themoviedb.org` на `127.0.0.1`, и вместе с API отваливается
`image.tmdb.org` — то есть и постеры. Поэтому каталог наполняется из
Кинопоиска: его постеры лежат на CDN, доступном там же, где и API. На сервере
TMDB работает, и импорт `--source tmdb` проходит.

**Кинопоиск падает по таймауту от «умных» фильтров.** Параметры `rating.kp`,
`votes.kp`, `notNullFields` заставляют API перебирать миллион документов:
страница отвечает 26 секунд вместо полутора. Поэтому `popular()` просит
выдачу, отсортированную по голосам, и отбирает подходящее **на нашей стороне**.

**Локальный пользователь не проходит гейт беты.** Свежий человек в локальной
базе получит «Нужен код-приглашение» на любой запрос. Либо выключите параметр
`beta_invite_required`, либо проставьте доступ:
`update users set access_granted_at = now() where tg_id = ...`. `preview_seed`
делает это сам.

**Порт 8000 может быть занят** чужим процессом — тогда uvicorn стартует, но
запросы уходят не туда, и вы отлаживаете вчерашний код. Проверяйте
`lsof -i :8000`; `scripts/preview.sh` для этого и берёт 8011.

**Переменная перед русским текстом в bash.** `"$PORT…"` в UTF-8-локали падает
с `unbound variable`: байты многоточия считаются продолжением имени. Пишите
`"${PORT}…"`.

**Уведомление без шаблона молча не уходит.** Добавили вид в `NotificationKind` —
добавьте ветку в `notify.render`, иначе запись пометится «нет шаблона» и
останется лежать.

**Цикл FK между `users` и `invite_codes`.** Он разорван через
`use_alter=True` на `users.invite_code_id`; без этого SQLAlchemy не может
упорядочить создание таблиц и ругается предупреждением.

**Тесты, зависящие от времени.** Окно сборки шорт-листа, «показ уже начался»,
дедлайны цикла — всё это привязано к календарю. Задавайте время явно
(`now=...`, `slot.starts_at = ...`), иначе тест начнёт падать вечером или
в другой день недели.

**Telegram-попапы требуют Bot API 6.2.** Методы в SDK есть всегда, но в старом
клиенте `showConfirm` не вызывает колбэк — обещание не разрешается никогда, и
интерфейс зависает. Проверяйте версию (`isVersionAtLeast`) или берите
`askConfirm` из `telegram.ts`.

## Куда смотреть, если что-то не так

| Симптом | Где искать |
|---|---|
| «Не удалось войти» в Mini App | подпись initData: токен бота в `.env` тот же, что у бота, открывшего приложение |
| «Нужен код-приглашение» | гейт беты, см. грабли |
| Пустой каталог | импорт не запускали: `app.import_top` |
| Бот молчит на `/start` | процесс `app.bot` не запущен — API на сообщения не отвечает |
| Кнопка Mini App ведёт не туда | `MINIAPP_URL` в `.env`; бот переставляет кнопку сам в течение секунд |
| Уведомления не приходят | таблица `notifications`: `sent_at`, `attempts`, `next_attempt_at` и `failed_reason` скажут, что случилось |
| Изменения в `.env` не видны | uvicorn без `--reload-include ../.env` |
